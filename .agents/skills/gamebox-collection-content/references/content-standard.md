# 收藏卡片内容生成规范

适用于猫猫百业、狗狗百业及后续收藏系列。新增系列、生成卡片、补写或改写故事时使用。
本规范用于后续新增与改写；采用状态以生产目录和对应编辑记录为准。
内容写作本身不授权修改抽取概率、收藏编号或界面。

## 目标与基调

稀有度越高，玩家能够读到的人物经历、行为动机和世界关联越丰富。
字数随层级增加，同时增加有效信息；普通角色也必须有自己的特点，不能成为敷衍的填充内容。

延续温暖、轻松、可亲近的动物职业世界。故事可以有小困难、遗憾、犹豫和成长，结尾应留有
安定感或希望。高稀有度可以更奇幻，但不要求力量更强、身份更尊贵或承担更宏大的使命。
一个认真完成普通工作的角色，也可以拥有值得珍藏的传说故事。

## 当前字段与展示边界

当前生产目录是 `app/lib/features/scratch/scratch_catalog.dart`，每张卡片已有：

| 字段 | 内容责任 |
| --- | --- |
| `groupId`、`index` | 系列归属与稳定收藏编号；生成文案不能改动已有编号或借用其他卡的位置 |
| `job`、`name` | 职业/称号与角色名字；同系列避免重名、同义称号堆叠 |
| `rarity` | 已分配的稀有度；决定下面的叙事要求，不能由生成器自行升降档 |
| `story` | 完整故事正文；可以分段，用实际换行或代码中的 `\n\n` 表达段落 |
| `clue` | 12–25 字的一句话人物线索，指向职业、习惯或画面道具，不复述故事结尾 |
| `imageAsset`、`artIndex`、`artRows` | 美术资源与裁切信息；须与角色和道具一致，不能通过改文案掩盖错图 |

目前故事写死在目录中，详情页直接显示 `story`；获得同一张卡时不重新生成故事。
`clue` 目前保留在数据里，当前 Flutter 界面没有展示它，不把它计算为玩家已读到的故事内容。
正文使用纯文本，不嵌入 Markdown 标题、JSON、字段名或生成过程说明。

长故事放在用户主动打开的详情中。不要为了执行此规范，自动把正文塞进图鉴卡面、中奖演出或
增加弹窗。现有详情虽可滚动，后续实际换上长文时仍需检查手机上的阅读和下方操作布局，
不能把“源码支持换行”当成长文 UX 已验收。

## 四档叙事要求

字数口径：统计正文中的汉字、字母与数字，标点、空格、换行不计；名字、称号和 `clue` 不计入。
表中范围为默认编辑目标，质量优先。超出范围时记录简短理由，不得通过空泛修饰或重复句子凑字数。

| 稀有度 | 正文字数目标 | 段落 | 必须提供的内容 | 读完应留下什么 |
| --- | --- | --- | --- | --- |
| 普通 | 30–60 字 | 1 段，通常 2–3 句 | 一个具体生活场景、一个动作、一个能认出角色的习惯或细节 | 记住“它是怎样的小家伙” |
| 稀有 | 80–140 字 | 1–2 段 | 在人物特点之外，写一件有起因、应对和结果的小事；至少一个明确动机或关系 | 记住“它做过什么事” |
| 史诗 | 160–240 字 | 2–3 段 | 一段相关来历、一次有分量的选择、选择带来的结果；至少两个具体细节，其中一个呼应画面 | 理解“它为什么成为现在的它” |
| 传说 | 280–400 字 | 3–4 段 | 一篇可独立读完的故事：起点、困难、主动选择、转变、落点；解释代表性道具/称号的由来，并关联同系列生活或人物 | 感受到“这一张有独属于它的篇章” |

高档包含低档的具体性要求。选择的分量可以来自时间、耐心、取舍、承认错误或向别人求助，
不必每张都写牺牲、灾难或拯救世界。允许开放结尾，但本卡的主要事件必须交代清楚。

传说至少有一处回扣：结尾重新出现开头的物件、动作或一句话，并让其意义发生变化。
史诗和传说都要保留一个日常细节，使人物可以被亲近，而非只有头衔和能力。

## 人物、世界与美术一致性

1. 先确定系列基调、职业、性格、动机、代表道具和关键动作，再写故事提纲与美术需求。
2. 新卡的美术和故事从同一份人物设定出发。既有图卡改写时，先查看原画，保留可见物种、
   服饰、道具和姿态；重点描写至少一个已经画出的细节。非画面中的往事可以补充，但不能与原画冲突。
3. 奇幻能力要有清楚的用途与边界，例如“灯能照路，却不能替人选择方向”，避免无所不能。
4. 角色联系只能引用已存在且核对过的人物，或本批明确登记的新人物。读者不必先集齐别的卡
   才能读懂本卡；关联用于增添趣味，不把主线结局锁在另一张卡里。
5. 已发布角色的名字、职业、物种和已写明事实保持一致。扩写可以补充过去，不能无说明地
   改掉既有身份、能力或关系。全批使用简单人物关系表避免互相矛盾。
6. 不把同一段故事换个名字给猫狗各用一次；相同职业可以共存，但人物动机、事件和解决办法要不同。

## 文风与常见退稿原因

- 用动作、对话、物件和选择表现性格；不要反复宣告“它很善良”“它勇敢又温柔”。
- 允许诗意，但至少能回答“谁，在什么处境下，做了什么”。如果删掉名字和职业仍适用于
  大部分卡片，说明故事缺少辨识度，应重写。
- 控制每段长度与生僻词，不连续堆新地名、组织名和历史名词；世界设定服务于这张卡的事件。
- 不依赖“最强、唯一、永恒、命运、守护一切”等形容词制造稀有感。
- 同批不要反复套用“曾经孤独—遇见伙伴—学会守护”、星光/月亮、迷路救援或获得王冠等同一套路。
  下面的范例是层级示范，不是要求后续角色沿用同一情节。
- 避免抽奖宣传、概率暗示、数值能力承诺和催促收集的话术。稀有度是收藏属性，不写成角色的自我评价。
- 不把开发注释、提示词、占位符或尚未证实的玩法能力混进玩家正文。

## 后续生成流程与交付格式

1. **读取现状**：读本规范、生产目录、对应系列说明；查看本次涉及的原画。列出固定事实和禁止改动项。
2. **规划整批**：为每张卡写一句人物核心与事件提纲，核对稀有度分布、名字和情节差异。
   保留轻松日常、幽默、协作、探索、创造等不同题材，不把全部高档都变成同一种英雄故事。
3. **生成正文**：按目标层级写故事与线索。高档先写清起因、选择和结果，再做语言润色。
4. **逐卡复核**：检查字数、叙事要素、人物辨识度、原画对应、固定事实和可独立阅读性。
5. **整批复核**：交叉检查人物关系、相似职业、重复开头/结尾、反复出现的意象及猫狗间的同文替换。
6. **集成与验收**：只有实际应用内容时才改目录；保持已有编号和存档兼容。按仓库规则执行
   所需测试与真实界面检查，重点看最长故事的换行、滚动、关闭与下方持有者区域。

作者交付两部分：

- **可应用内容**：逐卡给出 `index / groupId / rarity / job / name / story / clue`；新卡编号由目录规划分配，
  既有卡保留原值。美术需求/现有美术引用随卡附上，实际资源字段只填写已核实的数据。
- **编辑记录**：逐卡给出正文字数、人物核心、对应的叙事要素、画面呼应、关系核对和例外理由。
  编辑记录供审核使用，不放进 `story` 或玩家界面；不新增存储字段来承载写作过程。

可复用提示词：

> 为指定收藏系列生成或扩写卡片内容。先读取本规范和现有目录，列出固定事实，查看对应原画。
> 保持给定稀有度、名字、职业和稳定编号，按“四档叙事要求”逐卡完成故事。普通要有具体生活细节，
> 稀有要有事件，史诗要有来历与选择，传说要有完整人物篇章、道具由来和首尾回扣。
> 以温暖、轻松的动物世界为基调，用行动而非形容词塑造人物。同职业不复制情节，跨卡关系不自相矛盾。
> 输出可应用字段和独立编辑记录，明确字数、画面呼应与层级要求的满足情况。
> 不擅自更改概率、解锁条件、编号、UI 或存档，也不声称示例已应用到游戏。

## 四档改写示例

以下使用狗狗角色演示不同层级，已在本轮 48 张故事扩写中采用。
它们是深度参考，不是可直接换名复用的情节模板；后续改写需保留已采用的角色事实。

### 普通：消防员 · 火苗

火苗每次出勤前，都要把红头盔扶正两遍。今天救下树上的小鸟后，它又爬了一趟梯子，把落在枝头的小围巾也取了回来。

### 稀有：侦探 · 雷达

面包店低处的备货篮里接连少了三只牛角包，雷达循着碎屑找到了后院，却只看见一串小得出奇的脚印。它没有急着宣布破案，而是在墙边放下半只面包，蹲着等到天黑。

原来，新搬来的小刺猬够不着柜台，也不好意思开口。第二天，店门口多了一张矮凳。雷达合上笔记本，只写了一句：有些谜底，需要先听听肚子的声音。

### 史诗：极光巡守 · 北风

北风小时候，总把山顶的极光当作回家的路。有一年大雪封山，光带移到了山谷另一侧，它追着走了很久，直到一位老巡守提着灯找到它。那天北风才知道，好看的光，不一定会带人回家。

接过巡守的提灯后，它在每个岔路口系上能摸到的绳结，自己却迟迟不敢独自走完北坡。一次送药途中，风雪掩住了脚印，身后的年轻邮差问它怕不怕。北风点点头，把灯举低了一些：怕，所以我们走慢一点，一起认路。

现在，绿色的极光升起时，山下总能看见另一点缓缓移动的灯火。北风回到小屋，会先烘干同伴的手套，再给自己泡一杯热牛奶。

### 传说：星愿守护者 · 曜曜

曜曜还没有王冠时，只负责在小镇广场收拾庆典后的纸星星。别人挑走金亮的，它却会把皱掉的也装进口袋。有一颗上面写着：希望明天，还有人愿意听我唱歌。字迹被雨水泡开了，它一直没找到写字的人。

那年冬天，广场的许愿星忽然不再发光。大家以为是愿望不够大，写下更远的旅行、更高的城堡，星星却越来越暗。曜曜没有添上自己的纸条。它披着旧斗篷，挨家敲门，问每个人最近有什么想做、又没能做成的小事。它问得很慢，有时坐了半天，对方才肯说出第一句话。

它替怕冷的花艺师修好窗缝，陪不敢登台的乐手在空广场练习，也找到那张纸星星的主人，认真听完了一首总在同一处唱错的歌。每完成一件小事，斗篷上就亮起一点光。曜曜这才明白，星星不能替谁实现愿望，它们只是提醒大家，别把彼此的话忘了。

春天到来时，居民把那些重新发亮的纸星星编成王冠送给它。如今曜曜仍会在庆典后留下，弯腰捡起最后一颗皱纸星。它把王冠放在身旁，腾出两只爪子，轻轻将纸展开。无论上面写着什么，它都会从头读到最后。

# Project Agent Instructions

## UI change evidence

- Any change that affects the user-facing UI is not complete until the updated interface has been run in the relevant target runtime and captured in a screenshot.
- Include or attach the resulting screenshot in the final response by default; do not provide only a local file path. Capture the relevant state and viewport, and include multiple screenshots when one image cannot demonstrate the whole change.
- Use the actual built application for visual evidence. A mock, fixture, source inspection, or static rendering does not replace a screenshot from the target runtime.
- Keep credentials and other sensitive or user-specific data out of screenshots and retained artifacts.
- If a screenshot cannot be captured, report the exact blocker and state that visual verification remains incomplete.

# 飞行棋 HTML / Godot 对照验收

## 范围与基准

基准为 `flight-chess-outside-board-ux.html` 当前交互稿，目标为 Godot 生产场景 `flight_chess_scene.tscn`，采用 Lightweight Board。用户明确要求直接启动 Godot，不涉及 Android 服务。本次验证游戏自身布局、输入和表现；不将这组证据称为 Android 打包、真实网络或跨设备验收。

必须：三栏布局、紧凑图标计数、身份/回合/连接状态，手动选择与取消、路线预览、确认与 pending、叠机拆选、已确认移动/跳跃/捷径/撞机/归家/反弹、无棋可走、额外回合、断线/失败恢复、认输确认与结果、非破坏返回。保持服务端权威规则与消息格式。

应当：与稿件的信息层级、颜色语义、控件位置和动效次序一致。HTML 的“纸飞机”“飞行员”是示例昵称，现有启动协议不提供昵称，生产界面只显示阵营与真实连接状态，不伪造玩家名字。HTML 的演示台和演示大厅属于设计工具，不搬入生产界面；返回行为仍调用现有宿主退出回调。

可选：不同渲染器的字形、抗锯齿、阴影及边缘混色不要求逐像素一致。棋盘使用相同的 600 单位拓扑及实际阵营位置。

## 初次对照发现

- 旧 Godot 三栏留白较大，窄屏字小，缺少紧凑导航和操作面板；玩家卡仍有长句统计及示例昵称。
- 旧版点飞机即提交，缺少确认、取消、路线预览、叠机内明确选择。
- 除超点反弹外，其余已确认动作瞬移；抵达棋子仍堆在终点。
- 认输占用常驻空间；终局显示内部操作次数；连接与错误条跨越两侧栏。

## 验收结论

原先的整体视觉“通过”结论撤回：用户随后指出玩家卡留白失衡、重复提示和确认/取消间距问题，原复核未识别这些问题。下方保留此前功能验证证据；本次修正范围与实图复核另记于文末。未启动 Android 服务、模拟器或真实网络服务；本结论不覆盖 APK、宿主生命周期和双设备互通。

## 复核证据

- 浏览器打开当前 HTML 稿，检查默认三栏、选择与取消、撞机路线及结尾、终点收起、连接和终局状态；与 Godot 的同类状态按布局、层级、控件与表现次序对照。
- Godot 状态矩阵：800×360（20:9）、960×540（16:9），浅/深色，以及安全边距下的选中态。覆盖首次连接、待掷骰、菜单、规则、认输确认/等待/失败、走子拒绝、过期同步、重连、连接失败、无棋可走、胜/负/认输/取消/作废。
- Godot 动作矩阵：起飞、逐格、同色跳跃、跨航道、先跳后飞、整组撞机、叠机拆选、进入归家、精确抵达、超点反弹、6 点反弹、最后一架。检查选择/确认等待、移动中和落稳后；额外采样两架回库途中的画面、终点缩小淡出和折返中间帧。
- 实际视口 `push_input` 点击：掷骰、选中、取消、确认、更多菜单、点外部关闭、认输取消/确认、非破坏返回。菜单点击回归已加入生产场景测试，修复了 Godot 子节点输入顺序导致的卡片拦截。
- `bash tool/verify_fast.sh`：PASS（16 checks）。包含 Godot、Go、Flutter/Dart、设计系统和脚本确定性检查；没有借此声称设备验收。最终提示文案修改后另跑 `bash tool/verify_godot_tests.sh`：PASS（2 checks）。
- `bash tool/flight_chess_preview.sh --state full-game --viewport 960x540 --theme dark --step-delay 0 --screenshot <临时路径>`：PASS，104 个权威事件，52 次掷骰、52 次走子，双方均行动，23 次跳跃、8 次捷径，自然终局。此局未发生捕获，捕获由专项动作矩阵证明。

## 已修复的复核发现与保留差异

- 修复 16:9 侧栏缩放、确认/取消重叠、弹窗最小尺寸缓存撑大、字体阴影发黑、菜单可见但不可点，以及空白连接态伪造初始棋子。
- 飞机先完成移动/撞击/回库或抵达收起，再更新图标计数和当前回合；最后一架收起后才弹结果。队列保存每个确认事件的展示快照，避免后续事件抢占当前动画。
- 初次连接、等待确认、连接失败、认输等待与终局使用各自的提示，避免重复规则和错误恢复指引。
- 保留生产协议和实际阵营规则；HTML 示例昵称、模拟对手自动操作、演示大厅不迁入。提示文案与实际网络状态一致，不照搬实验台的模拟承诺。
- 保留 Godot 字体/矢量抗锯齿、原生骰子轮廓、紧凑叠机选择浮层和棋盘底部状态文字；不复刻 HTML 外部阴影、CSS 徽标渐变或每个装饰性过渡。回合卡在动作结束时切换，未额外叠加 HTML 的 200ms CSS 颜色渐变。这些差异不改变信息、操作顺序或动画的规则语义。

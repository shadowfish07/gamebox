# 海战棋舰船素材 v1

2026-09-15 使用 Codex 内置生图逐艘生成。本工作区没有带 POE_API_KEY 的本地 `.env`，因此未使用 Poe。素材已逐张检查；素材已接入 Flutter 海战棋的布阵、己方海域、击沉揭示及结算棋盘，运行资源位于 `app/assets/battleship/`。

| 文件名 | 舰船 | 占格 |
|---|---|---|
| carrier | 航空母舰 | 5 |
| battleship | 战列舰 | 4 |
| cruiser | 巡洋舰 | 3 |
| submarine | 潜艇 | 3 |
| destroyer | 驱逐舰 | 2 |

每艘提供 512×512 透明 PNG 和无损 WebP，原稿在 `originals/`。生成时要求 512×512，但实际原稿为 1247×1261 或 1254×1254；成品等比例缩小并居中补透明边，未拉伸。所有文件已验证尺寸、透明通道，以及 PNG/WebP 在明暗底色合成结果相同。

统一美术约束：正俯视、船头朝上、蓝灰船体、青绿细节、浅色轮廓、柔和顶部光照、完整船体，无海水、浪花、文字或旗帜。航母用飞行甲板与小型飞机，战列舰用三座重炮塔，巡洋舰用双炮塔与导弹箱，潜艇用流线艇身与潜水舵，驱逐舰用单炮塔与尾部停机坪区分。

`manifest.json` 记录资源名、规则占格、尺寸及边界。`alphaBounds` 是全部非零透明度像素范围，`visibleBounds` 是 alpha ≥ 32 的主体范围，坐标右下界不含。生成图片含少量低透明度边缘像素，接入时可用主体范围计算布局；原图保留完整透明通道。

接入建议：按主体比例等比绘制并整体旋转，不把整张正方形图拉伸为占格矩形。实际舰船造型较细长，规则占格继续由格子底纹/边框表达。命中、选中与击沉标记另行叠加。游戏按参与者视角绘制已知舰船，未击沉敌舰仍不显示；命中标记使用主题色底衬，绘制在舰船图片上层。

## 2026-09-07：传统刮奖、未中奖与收藏分组

### 范围与 Profile

Core Contract。用户要求删除多刮法，仅保留传统刮奖；降低获得藏品的概率并加入未中奖；游戏名称中立，分组仅用于收藏浏览。此前三模式验收属于历史版本。

### MUST / SHOULD / MAY

MUST：统一刮奖、不提供分组选择、可揭晓未中奖且继续、中奖才入册、收藏分组独立于游戏名称、兼容旧收藏。代码复核未发现阻塞项。
SHOULD：保留明暗主题、手机安全区、保存中/失败重试、返回与连续刮擦行为，无新增偏离。
MAY：中立暂名采用「刮刮收藏」，中奖率暂设 20%，中奖后四档比例不变。

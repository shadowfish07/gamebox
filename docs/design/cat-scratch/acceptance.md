## 实际 UI 检查

使用 Orca 内置浏览器运行构建后的独立 HTML，亲自打开并检查截图：默认页、局部擦除、揭晓、职业证锁定/线索、四格单格已开、新猫、重复猫、猫猫详情、传说预览、空/已收集图鉴、过滤、空/满展柜、满位提示、概率说明、存储失败与损坏提示。

检查 390×844、360×780、1280×960 浏览器 CSS 视口及明暗模式。曾发现浏览器 reload 后恢复桌面视口，重新设置并通过 `innerWidth` 和媒体查询核对后捕获窄屏截图。最终布局无横向溢出，纸票和猫猫原画在暗色背景仍清楚；手机为纵向滚动，主要操作在票面下方。

刮擦使用 Orca mouse move/down/up 发送真实鼠标输入，基于实际 canvas 几何定位。部分导航按钮在 Orca 引用点击的滚动定位不稳定时，通过实际页面 DOM `.click()` 激活生产事件路径；未通过替换奖励函数或预填稀有藏品来证明流程。异常测试是显式故障注入。QA 收藏均为此任务生成，已恢复初始空收藏供用户试玩。

## 交付与限制

- 独立文件：`artifacts/cat-scratch/cat-scratch-mvp.html`，构建命令见 [README](README.md)。
- 工作区预览服务仅绑定 `127.0.0.1:47863`，在 Orca 的「猫猫刮奖 MVP 预览」终端运行。
- 原大文件超出 Orca artifact 传输上限；资源压缩后分享被未登录状态阻塞（`authentication_required`）。Cloudflare 附件分享也因公网响应缺少匹配 Content-Length 校验失败，未交付未经验证的公网链接。用户可使用本机 URL 或打开独立 HTML。
- 未做 Android 安装/宿主接入、真机触摸/震动与音频听感验收；浏览器视口不等同于真机验收。仓库 APK 构建通过不意味着此 MVP 已包含在 APK。
- 本地收藏不可跨浏览器同步，也不防作弊；没有可信公共榜单。徽章当前复用同猫原画配金属框，尚未独立绘制专用徽章轮廓。

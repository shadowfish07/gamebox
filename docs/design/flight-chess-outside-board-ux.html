Godot 实现注释 · 状态、时序与边界

本稿沿用 Lightweight Board 布局：左侧身份、中央棋盘、右侧回合操作。拓扑与规则对应 flight_chess_board.gd / server/internal/games/flightchess/rules.go；红、黄参与对战，蓝、绿机场仅保留棋盘结构。

触发 / 状态画面与输入Godot 动画建议
按下 → 请求掷骰即时压缩；锁掷骰，等待时不显示虚构点数。按压 100ms；等待轻摆循环；roll.accepted 后 180ms 落定再亮可选飞机。
选机 → 预览可选机呼吸环；点选显示虚线路线和终点圈，可换选或取消。叠机先展开编号，哪怕仅一架合法也需手选。呼吸周期 1200ms；选中抬升 120ms。路线不改变棋局。
提交 → 等待确认飞机留在原位；右侧等待，保留预览；禁止重复提交。原位描边脉冲。pending 无移动音效、无撞机、无计分。
move.accepted → 移动锁输入，按顺序播放确认事件；逻辑快照先提交，表现层追赶。Tween：每格 140ms，轻微起落；起飞 420ms；同色跳 320ms；跨航道飞行 640ms，正交折线路径。
落点结算只在最终落点撞机；对方整组回库。同色轻量叠放不挡路，移动只移动选中一架。落点环 220ms → 被撞组并行回库 420ms → 叠机数量淡入 160ms。
归家 / 额外回合 / 终局精确点数归家；超点先到终点，再原路退回剩余步数；6 点再掷；最后一架到达后显示结果。反弹逐格往返，经过终点不计抵达；精确归家收束 360ms → 数量更新 → 换手 200ms；终局面板淡入上移 240ms。
失败 / 过期 / 重连失败保留骰点，可重新选择；过期与重连冻结最后确认棋局。恢复按快照重建，不重放历史撞机或胜利。取消 Tween 和旧回调；去掉预览。新快照 160ms 淡入。事件按 revision 去重。
返回 / 认输返回大厅保留可恢复对局；认输须二次确认。确认中不提前判负，结果后禁止再提交。退出取消表现队列；恢复先同步。认输确认后收到终局再播放结果。

推荐拆分：Board（静态拓扑）/ Pieces（确认位置）/ Preview（虚线与目标）/ Effects（移动、回库）/ HUD（回合与弹层）。只让本地状态机管理输入；服务端的 movablePieceIndices、from、to、effect、capturedPieceIndices 决定动作是否合法及最终结果。本稿的选中预览与确认按钮是待迁移的交互设计，非现有协议变更。

演示台可以载入固定局面、暂停在网络状态、注入一次走子失败，并用慢速查看动画。每个场景可重进重播；无真实网络、账号、大厅或音效。系统减少动态效果时压缩动效时长，保留状态顺序。

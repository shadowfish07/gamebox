# 抽卡收藏：连续翻卡流

状态：抽卡交互已批准；2026-09-08 纠正误改的每抽必得，恢复原有中奖概率。替代原刮奖主流程；保留原图鉴、猫狗两个收藏分组和玩家收藏。

## 抽取与数据

每次操作 20% 抽中、80% 落空；抽中后普通/稀有/史诗/传说分别为 70% / 24% / 5.5% / 0.5%，同档藏品等概率。仍为单人、免费、纯虚拟收藏；不新增支付、体力、保底、合成或跨设备权威存档。

一次点击确定中奖或落空，只有中奖更新数量与首次获得日期；结果串行保存，保存成功后开始揭晓。快速连点最多预接一张，不积压无限队列。失败保留原来的待保存奖励并清除预接操作，重试只保存同一结果，不重抽不重复发放。离开、切页、后台均停止后续自动抽取；已经进行的写入完成并保留本张奖励。

安全存储 key、收藏稳定编号、旧入口/导航 key 保留。版本 3 保存中奖标记；版本 2 去掉涂层字段；版本 1 的整面/分区/职业证存档完整验证后迁移，保留数量、日期、旧展柜字段及已确定的待领藏品。旧已领取中奖卡仅展示，不再次发放；旧空票保留落空结果，未揭晓旧票也保留原中奖标记。版本 2 已领取收藏保留；未领取候选只采样一次 20% 中奖标记并保存，不提前发奖。24 件旧存档补齐后续狗狗藏品的零数量。坏存档不覆盖。

## 主界面与单抽

中央大卡片，上方收藏进度与最多六张最近获得卡列，底部主按钮位置固定。点「抽一张」卡背从下方进入、绕竖轴翻面；下次点击将当前卡片缩小飞到最近获得卡列，接上下一张。落空时翻面显示「这次没有抽中」，不播放中奖特效、不进入最近获得，下次点击淡出后接下一抽。中奖卡面可点击查看详情；演出中点卡面可快进。

四档总演出约 0.4 / 0.7 / 1.2 / 2 秒，时长来自共享 motion token 的组合。普通轻弹扫光；稀有卡缝透绿光、星芒；史诗紫色扩散环；传说局部柔和压暗、金色多重环和放射星粒。揭晓触发系统 click 与轻/中/重触感（受系统声音/设备能力影响）。原画沿用现有美术，公共控件沿用 Material 3 tokens。

新藏品显示 NEW 与首次相遇，收藏进度随真实数量切换；重复显示「已拥有 ×N → ×N+1」并轻弹。旧结果恢复与切回页面不重播演出。

## 本次边界

按用户最新要求，先只提供单抽和连续点击，不提供十连入口、自动连抽或本轮汇总。动画结束后停留在当前卡片，等待下一次点击；用户停止点击后最多完成已经预接的一张。退出、切页或后台会清除这次预接。最近获得卡列仅保留本次会话的六张历史卡，不作为收藏存储。
